# Programming Artifact Pipeline

Every programming artifact follows: understand -> research -> plan -> build -> validate -> review -> deliver.

The validator is deterministic and separate from the model. Domain-specific checks will be added per artifact type.

Examples:
- ERD: entities, keys, relationships, cardinality, normalization checks.
- Flowchart: entry/exit, reachable nodes, decision branches.
- UML: structural consistency and relationship validity.
- Code: syntax, tests, static checks, dependency/security checks.
- Spreadsheet: schema, formulas, bounds, and output integrity.

External references are evidence only. Final artifacts must pass deterministic checks and reviewer evaluation before delivery.
