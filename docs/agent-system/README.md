# Universal Task AI — Agent System & Governance

This folder contains the canonical working rules for all AI agents. Begin with the repository root [AGENTS.md](../../AGENTS.md).

## Files

- [Agent Operating System](AGENT_OPERATING_SYSTEM.md): agent hierarchy A0–A13, decision rights, G0–G6 quality gates, design research SOP, screen/role catalog, shared workflow and security contracts, engineering rules, master prompt, specialist prompts, sprint roadmap, acceptance scenarios, and scorecard.
- [Product & Engineering Blueprint](PRODUCT_BLUEPRINT.md): product scope, system architecture, core workflows, data model, API plan, implementation roadmap, agent responsibilities, and coordination practices.
- [Design Reference Board](DESIGN_REFERENCE_BOARD.html): visual gallery of screenshot references with links to original sources. Open in a browser with internet access.
- [Design Reference Matrix](DESIGN_REFERENCE_MATRIX.md): per-screen inspiration, official behavioral sources, implementation references, and design synthesis rules.

## Source-of-truth rules

The governance document describes process and intent; the blueprint describes target architecture. Neither is proof that a feature currently exists. Verify current code, open PRs, and CI before every sprint. Mark every page/role design as NEEDS RESEARCH until a specific reference board is reviewed and the product owner records an approval. Never present design inspiration as a license to copy artwork or proprietary code.
